## 设计原则（两位 AI 的共识）

- **核心差异化 = 学习状态**："AI 知道你会什么、不会什么、下一步教什么"——概念掌握度系统（Kimi 的 `learner_concept_states` / GPT 的判断）
- **检索够用就行**：不引入 SQLite / 向量库大改，现有关键词检索 + 引用出处已满足（GPT 明确建议 FTS 先行）
- **闭环优先**：每个里程碑都是可交付的完整闭环
- **避免功能膨胀**：明确暂缓清单（GPT：功能膨胀是最大风险）

## 里程碑 1：概念掌握度系统（核心）✅ 已完成

**目标**：把"学没学会"从模糊印象变成结构化状态，并驱动复习和教学。

已确认决策：
- 概念识别方式：**对话中增量识别**（Kimi 方案）——每轮问答完成后异步识别本课概念与学习者表现，不预抽取（省成本）
- 展示位置：**复盘页「概念掌握」tab**

1. ~~概念状态存储 `concept-store.ts`（JSON 持久化 + EMA 更新）~~ ✅ 已完成
2. 概念抽取器 `concept-extractor.ts`（LLM 增量识别 + 表现判断 correct/partial/incorrect/unclear + 误解点）
3. 主进程接线：assistant 消息保存后异步触发 + IPC `concepts:list` + `concepts:updated` 事件
4. preload + global.d.ts 暴露 concepts API
5. 复盘页「概念掌握」tab 展示（掌握/理解/薄弱三档 + 误解点 + 尝试/答对 + 证据）
6. 单元测试 + 全量验证

数据模型（`LocalData/concepts.json`）：
- `mastery`（0-1，EMA：答对 +0.2(1-m)，部分 +0.1(1-m)，答错 -0.25m，未作答 -0.02）
- `misconception`（误解点，答对后清除）
- `attemptCount` / `correctCount` / `lastSeenAt` / `updatedAt`
- `evidenceConversationId` / `evidenceMessageIds`（证据溯源，Kimi 要求）
- 按 名称+教材 合并，id 由名称稳定生成（跨会话累计）

## 里程碑 5：AI 质量测试（Kimi 测试策略）✅ 已完成

固定教材 + 固定问题集，自动化验证：回答是否来自教材、引用是否正确、是否伪造引用、是否遵守苏格拉底式教学、是否错误直接给答案。

- 离线部分（默认 CI 必跑，`tests/ai-quality/quality.test.ts`）：
  - prompt 组装完整性：苏格拉底规则 / 教材段 / 引用格式段 / 概念掌握度段
  - 引用真实性规则：`extractCitations` + `citationMatchesTextbook`（规范化模糊匹配，6 字片段，防伪造引用）
- 在线部分（真实 LLM 端到端，无 key 自动跳过）：
  - 固定教材夹具 `tests/ai-quality/fixtures/textbook.md`（自编《函数与极限·入门讲义》，无版权）
  - 固定问题集：知识相关性 / 教材引用真实 / 苏格拉底式引导（拒绝直接给答案）/ 不脱离教材虚构
  - 运行方式：
    ```
    $env:SOPHIA_AI_QUALITY_KEY='<api key>'
    $env:SOPHIA_AI_QUALITY_ENDPOINT='https://ark.cn-beijing.volces.com/api/v3'  # 或官方 deepseek
    $env:SOPHIA_AI_QUALITY_MODEL='<模型或 ep-id>'   # 默认 deepseek-chat
    npx vitest run tests/ai-quality
    ```
  - 注意：coding-plan 类型 ARK key 无广场模型直连权限，需用平台 type profile 的 key 或官方 key
