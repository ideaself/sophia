# ADR-005: 预设角色

## Status

Accepted（2026-09-16 修订：预设精简为 3 个原创文案角色）

## Context

`reference/角色设定/candidates/` 提供内置预设角色，随安装包分发并在初始化时加载进
本地候选角色池。预设面向主要学习科目：物理、数学、英语。

## Decision

- 预设角色固定为 3 个：朗道（物理）、祖冲之（数学）、艾米莉·卡特（英语）。
- 全部文案为原创；基于真实历史人物的角色仅使用公开生平与学术观点，不引用任何受版权
  保护的作品原文，也不使用影视/改编作品中的标志性台词或形象。
- 新增角色沿用同一格式（基本信息 / 性格详写 / 说话风格与示例 / 情绪表现）。

## Alternatives Considered

### 保留更多角色
- Pros: 可选择性更多。
- Cons: 内容审查与维护成本高，与科目定位不符。
- Rejected：v0.1.2 起精简为 3 个。

## Consequences

- Prompt builder 需对任意角色 Markdown 稳定工作；
- UI 提供角色选择器；
- 测试覆盖 3 个预设角色的加载与 schema 校验，并对关键字段做断言。
