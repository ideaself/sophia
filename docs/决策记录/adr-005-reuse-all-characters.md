# ADR-005: 内置九个候选角色

## Status

Accepted（2026-09-16 修订：公开分发前重写全部角色文案）

## Context

`reference/角色设定/candidates/` 提供 9 个候选角色 Markdown（爱丽丝、福尔摩斯、孙悟空、
沈砚、江雨眠、顾长明、秦歌、陆沉舟、许清扬），初始化时加载为内置角色。

项目公开后，分发内容必须为原创或公有领域表达：其中爱丽丝、福尔摩斯、孙悟空为公有领域
文学形象（仅使用原著设定，文案为原创），其余 6 个为本项目原创角色。

## Decision

- 内置全部 9 个角色作为候选角色，Markdown 原文加载为 companion 数据；
- 角色文案必须为原创表达；基于公有领域形象时，不得使用影视/改编作品中的标志性台词或形象；
- 新增角色沿用同一格式（基本信息 / 性格详写 / 说话风格与示例 / 情绪表现）。

## Alternatives Considered

### 只保留一个角色
- Pros: 实现更快。
- Cons: 无法验证角色选择与 prompt 泛化。
- Rejected.

### 保留来源不明的角色文案
- Pros: 省事。
- Cons: 公开分发第三方提取文本存在版权风险。
- Rejected：v0.1.2 起全部重写为原创文案。

## Consequences

- Prompt builder 需对任意角色 Markdown 稳定工作；
- UI 提供角色选择器；
- 测试覆盖 9 个角色的加载与 schema 校验，并对爱丽丝/福尔摩斯做字段断言。
