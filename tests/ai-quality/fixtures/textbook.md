# 函数与极限 · 入门讲义

> 自编教学夹具（无版权问题），用于 AI 质量测试。

## 1. 函数

函数是从一个数集到另一个数集的对应规则：对定义域中的每一个数 x，恰好对应唯一一个数 y，记作 y = f(x)。定义域是 x 可以取的所有值，值域是 y 实际取到的所有值。

## 2. 极限

极限描述的是 x 无限接近某个数 a 时，f(x) 的取值趋势。教材采用如下说法：

> 如果当 x 趋近于 a 时，f(x) 无限接近常数 L，则称 L 是函数 f 在 x = a 处的极限，记作 lim(x→a) f(x) = L。

极限强调"趋近的过程"，与函数在该点是否取值无关。函数在 a 处可以没有定义，极限仍然可能存在。

## 3. 极限的性质

- 唯一性：如果极限存在，那么极限值是唯一的。
- 四则运算：极限的和等于和的极限，前提是两个极限都存在。
- 夹逼定理：如果 g(x) ≤ f(x) ≤ h(x)，且 g 与 h 在 x = a 处极限都为 L，则 f 在该处的极限也为 L。

## 4. 连续

函数 f 在 x = a 处连续，需要同时满足三个条件：f 在 a 处有定义；极限 lim(x→a) f(x) 存在；极限值等于函数值 f(a)。直观地说，连续函数的图像在该点没有断开。

## 5. 常见误区

误区一：把极限值当作函数值。极限描述趋势，函数值描述该点的实际取值，两者只在连续时相等。

误区二：以为极限存在则函数必须有定义。例如 f(x) = (x² - 1)/(x - 1) 在 x = 1 处没有定义，但极限为 2。
